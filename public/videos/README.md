Place Leila's supplied video files in this folder, then add their entries to `src/data/videos.ts`.

Use browser-compatible MP4 (H.264/AAC) or WebM. Each entry needs an id, title,
category (`Commercials`, `Video edits`, or `Motion`), and src such as `/videos/film.mp4`.
An optional poster image and description can also be provided.

Videos load only after being selected in the TV library. Leaving the TV pauses playback.
